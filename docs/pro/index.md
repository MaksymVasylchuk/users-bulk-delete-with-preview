# Pro add-on

**Users Bulk Delete With Preview Pro** is a paid add-on for the free plugin. It adds what you need to clean up users regularly and safely: a way back, automation, and many more filters.

[Buy or start a 7-day trial](https://checkout.freemius.com/plugin/43896/plan/77316/){target="_blank"}

::: warning Pro needs the free plugin
Install and activate [Users Bulk Delete With Preview](https://wordpress.org/plugins/users-bulk-delete-with-preview/) (version 2.5.0 or newer) first. See [Installation and license](./installation).
:::

## What Pro adds

| Feature | In short |
|---|---|
| [Recycle bin](./recycle-bin) | Deleted users are kept for 30 days and can be restored with their password, profile, roles, posts and WooCommerce orders |
| [Saved filters](./saved-filters) | Save the filters of the Bulk Users Delete page under a name and load them again |
| [Scheduled cleanups](./scheduled-cleanups) | Run a saved filter from every hour to every 30 days: email a report or delete the users, with warning emails first |
| [More filters](./filters) | Last login, spam signs, fraud signals, WooCommerce purchases and subscriptions, memberships, LearnDash, Tutor LMS, BuddyPress, Ultimate Member, lists of users |
| [Protection](./protection) | Never delete chosen roles, users, email domains, paying members or customers; deleted users cannot register again |
| [WooCommerce customer data](./woocommerce) | Remove personal data from orders, delete unpaid orders, cancel subscriptions, revoke downloads |
| [Notifications](./notifications) | Email when a background deletion finishes, a webhook, and an optional email to deleted users |
| [Export columns and last logins](./export-and-logins) | More CSV columns, CSV export of the log, import of last logins from other plugins |
| [Multisite network](./multisite) | Delete accounts that belong to no site, with a network recycle bin |
| [WP-CLI](./wp-cli) | `wp ubdwpp filters`, `wp ubdwpp schedules`, `wp ubdwpp bin`, `wp ubdwpp logins` |

## Where to find it

Pro adds pages and tabs to the menu of the free plugin:

- **Bulk Users Delete → Recycle Bin**
- **Bulk Users Delete → Scheduled Cleanups**
- **Bulk Users Delete → License** (and **Account** after activation)
- **Settings** tabs: Recycle bin, Protection, Customer data, Notifications, Export, Logins
- On multisite, in the network admin: **Users → Accounts Without a Site**

## Requirements

- The free plugin, version 2.5.0 or newer
- WordPress 6.2 or newer, PHP 8.0 or newer
- A license or an active trial. Without one, the Pro features are off, but their data (recycle bin, schedules, saved filters, settings) is kept and comes back when a license is activated.

# Installation and license

## 1. Install the free plugin

Pro is an add-on: it needs the free plugin.

1. **Plugins → Add New**, search for **Users Bulk Delete With Preview**.
2. **Install Now**, then **Activate**. Version 2.5.0 or newer is required.

## 2. Install Pro

1. Download the Pro zip: use the link in the purchase email, or log in to the [Customer Portal](https://users.freemius.com/).
2. **Plugins → Add New → Upload Plugin**, choose the zip, **Install Now**, then **Activate Plugin**.

## 3. Activate the license

1. Go to **Bulk Users Delete → License**.
2. Enter the license key from the purchase email and click **Activate License**.

The Pro features appear right away on the Bulk Users Delete, Recycle Bin, Scheduled Cleanups and Settings pages.

::: tip Can't find your license key?
Click **Can't find your license key?** on the activation screen, or find it in the [Customer Portal](https://users.freemius.com/).
:::

## The License and Account pages

- **License** shows the state of the license (active, trial, not active).
- **Account** (provided by Freemius) shows your plan, license key and payments, and lets you change the license, change the plan, sync the license, download invoices or cancel the subscription.

## Updates

New versions of Pro appear in **Dashboard → Updates** and on the **Plugins** page like any other plugin, as long as the license is active.

## Multisite

Activate Pro on each site that should use it, or network activate it. The license is activated per site, and each site counts as one activation of your license.

## Moving to another site

**Account → Deactivate License** frees the license on the current site, so you can activate it on another one. Deactivating or deleting the plugin frees it too.
